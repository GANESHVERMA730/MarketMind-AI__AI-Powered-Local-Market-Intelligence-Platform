# MarketMind AI — client

React + Vite frontend for MarketMind AI (Phase 4).

## Setup

```bash
npm install
copy .env.example .env
npm run dev
```

The API base URL comes from `VITE_API_URL` (default `http://localhost:5000/api`). The Express server and MongoDB must be running for login, inventory, sales, and analytics. Register a shop account from the app; there is no seeded account yet.

## Build and tests

```bash
npm run build
npm test
```
